# صيدلية الأمل - Al-Amal Pharmacy

نظام إدارة صيدلية متكامل مبني بتقنيات حديثة.

## التقنيات المستخدمة

### Backend
- Node.js + Express.js
- Sequelize ORM + MySQL
- JWT Authentication
- Multer (رفع الملفات)

### Frontend
- React.js (Vite)
- React Router v6
- i18next (دعم عربي/إنجليزي)
- Lucide Icons

## الميزات
- 🛒 سلة مشتريات متكاملة

## تشغيل المشروع

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
```
